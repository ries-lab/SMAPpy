# Porting candidates

Every candidate from the survey in one table: the fixes to SMAPpy's own code first, then
ports and re-implementations, then user-experience ideas, each by priority (3 high, 1 low).
The same table, filterable and sortable, is an artifact page; this file is the copy that
stays with the repository.  Details, code references and DOIs are in the linked files.

*Size*: S ≤ a day, M a few days, L a week or more, with page and tests (the survey agents'
estimates).  *Route*: **port** = MIT / BSD / Apache, copy with attribution; **own** = Ries-lab
code (SMAP, LocMoFit, fit3Dcspline); **re-implement** = GPL, no licence or no public code, from
the paper only.  Priorities follow the shortlist in [README.md](README.md); those of items off
the shortlist and of the UX ideas were assigned when the table was made.
